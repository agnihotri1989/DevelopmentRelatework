```
## Aaj ka Goal: Block 0 — JavaScript/ES6 Essentials

Main JavaScript/ES6 basics nahi jaanta. Mujhe ye 6 topics sikhne hain — har ek ko Kotlin/Android se compare karke samjhao:

1. **Arrow Functions** → Kotlin lambdas se compare
2. **Template Literals** → Kotlin string interpolation se compare
3. **Destructuring** (Object + Array) → Kotlin componentN() se compare
4. **Spread Operator (...)** → Kotlin copy() se compare
5. **Array Methods (map, filter, find)** → Same as Kotlin collections
6. **Async/Await** → Kotlin Coroutines se compare

---

## Rules:
- **Lego approach:** ek concept ek time, pehle wala clear ho tabhi agle pe jao
- **What, Why, How:** har concept ke liye
- **Kotlin/Android Analogy:** har concept mein — mujhe familiar lagni chahiye
- **Tum mentor ho:** explain karo, examples do, phir mujhse practice karwao
- **Action mat lo:** Code tum mat likho, mujhe batao kya likhun — main likhun
- **Mini exercises:** Har concept ke baad ek chhota exercise do jo TaskMatrix project se related ho
- **Checkpoint:** Saare 6 topics ke baad ek final checkpoint quiz lo

Shuru karo topic 1 (Arrow Functions) se. Pehle What/Why batao, phir Kotlin comparison, phir mujhe ek exercise do.
```
